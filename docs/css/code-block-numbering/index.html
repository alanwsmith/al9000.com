Adding Line Numbers to HTML Code Blocks Using data- Attributes and CSS

July 2026

Numbers of Lines

I've been using CSS counter to add line numbers to code blocks forever. For example, this HTML and CSS:

<pre class="example-1"><span class="line-number"></span>fn main() {
<span class="line-number"></span>  println!("Hello World");
<span class="line-number"></span>}</pre>
.example-1 .line-number {
  counter-increment: example-line-number-1;
}

.example-1 .line-number::before {
  content: counter(example-line-number-1);
  padding-right: var(--default-padding);
}
Produces this output: 
fn main() {
  println!("Hello World");
}

It works great for basic code blocks that start at "1" and go up from there.

Start Position

Starting with another number is possible via the counter-reset property. For example, you can start the line numbers at "7" like this:

<pre class="example-2"><span class="line-number"></span>fn main() {
<span class="line-number"></span>  println!("Hello World");
<span class="line-number"></span>}</pre>
.example-2 {
  counter-reset: example-line-number-2 6;
}

.example-2 .line-number {
  counter-increment: example-line-number-2;
}

.example-2 .line-number::before {
  content: counter(example-line-number-2);
  padding-right: var(--default-padding);
}
Which outputs: 
fn main() {
  println!("Hello World");
}

The Skipping Problem

The problem I've been running into is how to show some parts of the code while skipping others. For example, say I've got this code block:

fn main() {
  let alfa = "thing 1";
  println!("{}", alfa);

  let bravo = "thing 2";
  println!("{}", alfa);
}

But, instead of display the entire thing I only want to show the opening and closing of the main function and the alfa lines. It's easy enough for me to remove the bravo lines in my output, but the lines number for the closing } would be different when I show the full code.

Something like this:

fn main() {
  let alfa = "thing 1";
  println!("{}", alfa);
  
}

I could use the counter-reset approach to set the line number. That would get complicated fast and require customization for each block that involves removing lines. That also wouldn't handle adding the . for the empty line position.

Solution Attributes

Enter the CSS attr() function. It's been around since 2015 and provides a better way to control line numbering. Specifically, it lets you grab the value from a data-* attribute in an HTML element for display.

Here's the code that makes it work:

<pre class="example-4"><span class="line-number" data-num="1"></span>fn main() {
<span class="line-number" data-num="2"></span>  let alfa = "thing 1";
<span class="line-number" data-num="3"></span>  println!("{}", alfa);
<span class="line-number" data-num="."></span>  
<span class="line-number" data-num="7"></span>}</pre>
.example-4 .line-number::before {
  content: attr(data-num);
  padding-right: var(--default-padding);
}
And here's what it looks like: 
fn main() {
  let alfa = "thing 1";
  println!("{}", alfa);
  
}

Exactly what I'm looking for.

Endnotes

  • This approach presupposes you have the ability to control that HTML for your code blocks. That is, you need a way to determine which lines show up and what the associated `data-num` attributes for each one are.
  • I removed syntax highlighting from the HTML of the examples to make them easier to read. The approach works when highlighting is applied as well.

  • Another idea I'm toying with is adding a specific class to the lines where splits occur to collapse the separation into a single border line. 

    fn main() {
  let alfa = "thing 1";
  println!("{}", alfa);
}

    That needs some help, but I like the direction.
