They do things like make it easier for me to collect quotes, make blog posts, and the like. I'm using Rust's axum[@ footnote("axum") @] crate for the web server. It's bare-bones. Making the tools involves setting up routes and associated functions for every action. This page is my basic template for Creating, Reading, Updating, and Deleting (CRUD) content. NOTE: This is a work in progress. While the initial functionality is in place, there are still user experience improvements to make and security issues to be addressed. ## The Files I put all the Rust code in a single file for ease of editing. It's a couple hundred lines that run the server and provide the interactions. Four HTML template files round out the code. One's a wrapper.
