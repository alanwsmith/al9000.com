A Basic Rust/Axum Static Site Generator

July 2026

Notes

  • Generates a static site.

  • Uses MiniJinja for templating.

  • Every content file is treated as a template.

  • Serves a local copy of the static site.

  • Serves an admin site for adding dynamic tools.

  • The local sites hot reload.

  • The admin server has the ability to do one off flash messages.

  • Logging is provided. I'm using a custom formatter for it that allows messages to go to the console as well as a file.

  • Files with .raw in their name don't go through the template engine.

  • Files with .inc in their name don't get pushed to the site (they can still be used as includes, though).
