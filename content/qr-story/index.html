Alice in QR Land

This piece is the text of Alice's Adventures in Wonderland with each word turned into a QR code. The color of each code is random. The codes are generated each time the page is loaded. It can take some time. Some devices may struggle. (There are more efficient ways to do the same thing. This is about playing with the tech more than optimizing performance.)
