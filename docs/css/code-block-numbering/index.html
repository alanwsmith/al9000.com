Adding Line Numbers to HTML Code Blocks Using data- Attributes and CSS

July 2026

Numbers of Lines

I've been using CSS counter to add line numbers to code blocks forever. For example, this HTML and CSS:

<pre class="example-1"><span class="line-number"></span>fn main() {
<span class="line-number"></span>  println!("Hello World");
<span class="line-number"></span>}</pre>
.example-1 .line-number {
  counter-increment: example-line-number-1;
}

.example-1 .line-number::before {
  content: counter(example-line-number-1);
  padding-right: var(--default-padding);
  display: inline-block;
}
Produces this output: 
fn main() {
  println!("Hello World");
}

It works great for basic code blocks that start at "1" and go up from there.

Start Position

Starting with another number is possible via the counter-reset property. For example, you can start the line numbers at "7" like this:

<pre class="example-2"><span class="line-number"></span>fn main() {
<span class="line-number"></span>  println!("Hello World");
<span class="line-number"></span>}</pre>
.example-2 {
  counter-reset: example-line-number-2 6;
}

.example-2 .line-number {
  counter-increment: example-line-number-2;
}

.example-2 .line-number::before {
  content: counter(example-line-number-2);
  padding-right: var(--default-padding);
  display: inline-block;
}
Which outputs: 
fn main() {
  println!("Hello World");
}
