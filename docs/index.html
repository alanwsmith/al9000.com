Welcome to al9000

My main site is alanwsmith.com. It's been around for ~25 years. It's been great, but I like the idea of a site that's not my name. So, I'm making this one.

I've made a ton of little sites that are under the alanwsmith.com domain. A big reason for that is because the tools I use to build the main site weren't well set up to make independent pages. I'm writing new software to make that easier to do here. It'll make maintaining and navigating between different experiments a lot easier.

The current list of stuff and statuses is below. Stop back by every now and then to check for updates. (Getting an RSS Feed in place is on the list.)
