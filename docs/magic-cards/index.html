Making Cards

  • I'm getting background from deviant art

  • I'm using Card Conjurer to make the card images

  • The frame I'm using is: Regular - Borderless Stations - Colorless Frame. Add it twice to get a darker transparent background.

  • For the power/toughness I'm using: Regular - Regular Frames - Black Power/Toughness

Using Cards

To use a card in Tabletop Simulator, do the following:

  1. Import a deck from archidekt (or wherever)
  2. Save the deck as an object in TableTop Simulator
  3. Edit the URLs for the images in ~/Library/Saves/Saved Objects/*.json
