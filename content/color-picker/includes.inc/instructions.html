Instructions
  1. Select the Mode you want to work on (either light or dark)
  2. Use the Background sliders to set a background color. As you do, the colors in the Colors section update automatically (each hue value rotates 45 degrees).
  3. Choose a color from the Colors section and use the "hue" buttons below it to select the hue portion of it's OKLCH value.
  4. Use the Lightness and Chroma sliders to adjust those values for the color.
  5. Copy the CSS block and paste it into your style sheet to start using the colors.
