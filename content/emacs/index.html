In the docs, "kill" is effectively "cut" - {{C-SPC}} is how you mark regions (e.g. for killing) - {{C-w}} kills (cuts) the current selection that can be pasted elsewhere. The killed contents are put on the __kill ring__ which contains all the stuff that has been killed previous.
