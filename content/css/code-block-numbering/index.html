For example, this HTML and CSS: == filter highlight_block("html") == include f.dir + "/example-1/code.html" == endfilter == filter highlight_block("css") == include f.dir + "/example-1/styles.css" == endfilter Produces this output: == include f.dir + "/example-1/code.html" It works great for basic code blocks that start at "1" and go up from there. ## Start Position Starting with another number is possible via the `counter-reset` property. For example, you can start the line numbers at "7" like this: == filter highlight_block("html") == include f.dir + "/example-2/code.html" == endfilter == filter highlight_block("css") == include f.dir + "/example-2/styles.css" == endfilter Which outputs: == include f.dir + "/example-2/code.html" ## The Skipping Problem The problem I've been running into is how to show some parts of the code while skipping others. For example, say I've got this code block: == include f.dir + "/example-3/code.html" But, instead of display the entire thing I only want to show the opening and closing of the `main` function and the `alfa` lines. It's easy enough for me to remove the `bravo` lines in my output, but the lines number for the closing `}` would be different when I show the full code. Something like this: == include f.dir + "/example-3/code-b.html" I could use the `counter-reset` approach to set the line number. That would get complicated fast and require customization for each block that involves removing lines. That also wouldn't handle adding the `.` for the empty line position. ## Solution Attributes Enter the CSS `attr()` function. It's been around since 2015 and provides a better way to control line numbering. Specifically, it lets you grab the value from a `data-*` attribute in an HTML element for display. Here's the code that makes it work: == filter highlight_block("html") == include f.dir + "/example-4/code.html" == endfilter == filter highlight_block("css") == include f.dir + "/example-4/styles.css" == endfilter And here's what it looks like: == include f.dir + "/example-4/code.html" Exactly what I'm looking for. -a
